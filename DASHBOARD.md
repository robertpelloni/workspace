## Directory Layout Explanation

- **Root Directory**: Contains the core configuration files (`package.json`, `opencode.json`, `sst.config.ts`), documentation (`DASHBOARD.md`, `CHANGELOG.md`, `ROADMAP.md`), and infrastructure definitions (`infra/`).
- **Submodules**: All external tools, agents, and libraries are checked out as git submodules. They are located in their respective directories at the root level (e.g., `AIOS/`, `OpenHands/`).
- **AIOS/**: The AI Operating System core logic and agent definitions.
- **scripts/**: Helper scripts for project maintenance (e.g., dashboard generation, updates).

## Updates
- All submodules are configured to track their respective upstreams.
- Version tracking is centralized in `VERSION` and `CHANGELOG.md`.
