# workspace — Robert Pelloni's omni-workspace (federated monorepo)

This repository is the central development workspace for Robert Pelloni's whole software ecosystem: a **federated monorepo** that pulls his projects together as **112 git submodules** (per `.gitmodules`) — HyperNexus/TormentNexus, bob's game, rhythm games, audio tools, browser forks, and a shelf of upstream mirrors — plus the orchestration layer that keeps them in sync: branch/submodule inventory tooling, build-result tracking, and hand-off documents for the AI-assisted development process.

It is personal infrastructure, not a product. There is nothing to install from here directly; the value is the map (`SUBMODULE_INVENTORY.md` / `SUBMODULE_INVENTORY.json`, `SUBMODULE_MAP.md`, `STRUCTURAL_MAP.md`) and the sync/analysis scripts (`analyze_branches.py`, `add_banner.py`, and friends).

## Layout

- **Submodules** — most top-level directories are gitlinks to other repos (his own projects and upstream mirrors such as FFmpeg, GWEN, MarbleBlast, OpenMBU). A plain clone gets you pointers, not code.
- **Orchestration & reports** — `SUBMODULE_DASHBOARD.md`, `BUILD_RESULTS.md`, `DASHBOARD.md`, `DEPENDENCY_RESEARCH.md`, `DEPENDABOT_TRIAGE_REPORT.md`, `VULNERABILITY_REPORT.md`, `AI_CONTRIBUTION_REPORT.md`
- **Process docs** — `VISION.md`, `ROADMAP.md`, `TODO.md`, `HANDOFF*.md`, `MEMORY.md`, and per-assistant instruction files (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `GPT.md`)

## Working with it

```bash
git clone https://github.com/robertpelloni/workspace.git
cd workspace
git submodule update --init <path>   # init only what you need — a full recursive
                                     # checkout is many gigabytes
```
